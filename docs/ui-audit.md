# 官网持续 UI 审计

## 方法与设计约束

- 目标：使用 Refactoring UI 规则持续审计并修复官网；保留既有品牌风格、定价与功能承诺、演示行为和双语结构。
- Skill：`.agents/skills/refactoring-ui/SKILL.md`，上游 `edisonmbli/refactoring-ui-skill`，版本 `4459662c4fbf36d54342b1546d8851273031442c`。Skill 已安装于项目，后续对话可按根目录 AGENTS.md 加载。
- 技术栈：React 19 / TanStack Start SSR；Tailwind CSS 4；shadcn new-york / Radix；CSS tokens 位于 src/styles.css。
- 无全局深色模式；深色极光展示区是既有设计约定。保留其中背景和动画，不强行替换为规则书示例。现有 12–21px 正文字级、圆角与灰阶属于既有系统，不因与 Tailwind 默认阶梯不同就判为缺陷。
- 固定顺序：层级 → 布局/间距 → 排版 → 色彩 → 深度 → 图像 → 收尾。
- 首轮：2026-10-23，本地 localhost:3000，1280×900 / 375×900，中英文。11 类模板（首页、价格、下载、关于、博客列表、更新日志、隐私、条款、审核包、两篇文章），共 44 份渲染和尺寸/对比度测量。
- 原始记录与截图：`/tmp/void-ui-audit-20261023/`。机器测量跳过渐变背景、未完成入场动画、disabled 及 aria-hidden 装饰；这些区域必须另以截图与真实交互核对，不能把“未报告”当作通过。

## 系统性发现

1. 场景内插图与真实可交互控件需要分开检查：前者允许在本组内裁切，后者不能用 overflow-hidden 隐藏。尤其不能给 body 加 overflow-x:hidden 来掩盖上述溢出。
2. 品牌填充色 `--brand` 与小字色 `--link` 已经分开定义，但部分浅色卡片仍把填充色当小字色使用。沿用既有 token 分工即可，不需要新色板。
3. 现有页头页脚、正文行长、图片、卡片层级在初轮子页面上未发现同等严重问题；尚未完成全文章与动态状态核查，不能宣称全站完成。

## 2026-10-25 演示开场锁屏、拉高、AI 思维链

- 高度：演示窗口主体从 `clamp(200px, 100svh-400px, 600px)` 改为 `clamp(320px, 100svh-290px, 820px)`。实测 1280 × 800：演示画面从 59px 到 696px，场景切换条底部在 768px，几乎占满页头以下的一屏。
- 开场（参考 tryalcove.com）：演示先是一块 Mac 锁屏，包括壁纸、刘海里带锁的岛（和收起的 Island 同宽同高）、日期、大号时间和「点按即可解锁」。演示画面有 55% 进入视口后，0.65 秒自动解锁，也可以直接点。解锁后锁屏内容上移淡出，0.38 秒时 Island 自己弹出 AI 标签，1.15 秒时日历窗口从下方浮上来；Island 2.6 秒后收回，指针停在岛上时不收。锁着时暂停演示自动播放，日历窗口设为 inert；减少动态效果时直接解锁。
- AI 思维链：照应用的 `ThinkingTimeline`。思考时展开，显示流光的「思考中」和秒数；每步一行挂在竖线上，读取类步骤带标签胶囊，推理只写小标题，进行中的步骤转圈。想完以「完成思考 · N 步」收尾，随后收起成「思考了 N 秒」，可以点开。排程、顺延、捕获三个场景和用户自己输入的请求都会先显示思维链。
- 每日笔记的「晨间准备」改成第一人称、具体的待办（PRD、周五分享、Mia 的邮件、健身），替换原来的功能说明式清单；英文同步。
- 实测：中文 1024 和 1280 × 800 下看了锁屏 → 解锁 → 岛弹出 → 窗口出现的过程，以及思维链进行中和收起展开两种状态；英文 375 下看了解锁后的演示和「Thought for 2s」。手机锁屏本身只确认了 DOM 和尺寸（锁屏条和收起的岛都是 40 高），截图前已经自动解锁，没有截到锁屏画面。
- `bun run typecheck`、`bun test`（31 通过）、`bun run build` 通过。未部署。
- 解锁音效：用 Web Audio 现场合成「咔嚓」，先是一下轻的高频，紧跟一下重的中频，再垫一点低频，不使用音频文件（Alcove 用的是它自己的 unlock.wav，不拿来用）。浏览器只允许访客点过或按过键的页面出声：点锁屏解锁一定有声音；只是滚动到这里自动解锁、页面还没被点过时就静音解锁。实测点锁屏时两段噪声都播放了。
- 场景切换条：照电视节目条的分栏样式。黑底（#141416）、8px 圆角、栏与栏之间 1px 细线。当前栏从左往右亮一档（16% 白，约 #3a3a3c）表示播放进度（试过底边加 3px 白线，太跳，已去掉）；字始终是白色（在填充上 11:1），未选中 60% 白（6.7:1）。试过整块纯白填充，和黑底反差过大、字被切成黑白两半，已放弃。桌面带「01–04」序号，手机隐藏；375 英文四个标签都放得下。
- 修复：锁屏原来和 Island 共用同一个「暂停自动播放」标记，解锁后偶尔一直停在 0%；改成各用各的标记。自动解锁改为在滚动事件里直接计算可见比例，不再只依赖 IntersectionObserver。实测解锁 → Island 弹出时暂停 → 收回后进度从 7% 走到 60%。
