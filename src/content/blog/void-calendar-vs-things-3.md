如果你觉得 [OmniFocus](/blog/void-calendar-vs-omnifocus) 太复杂，那么你大概率也会看看 Things 3。它们都有很好的原生交互体验，也都有自己的任务管理哲学。

我很喜欢 Things 3。我的轻量任务一直都放在那里，因为它足够简单，想到一件事，随手记下来就行。

**一句话结论**：如果你要的是在 iPhone、iPad 和 Mac 上快速记下轻量任务，一次买断、界面优雅，Things 3 很难被替代。如果你的任务需要完整的笔记，还要知道一天里到底有没有时间做，想让 AI 把任务排进日历的空闲时段，Void Calendar 更合适。

## 一览对比

| | Void Calendar | Things 3 |
| --- | --- | --- |
| 平台 | macOS（Apple 芯片），公开测试版 | Mac、iPhone、iPad、Watch、Vision Pro |
| 价格 | 免费版含全部功能；Pro 同步暂未开售 | 各平台分别一次性购买，无订阅 |

## 简单，是我喜欢它的原因

先把东西放进 Inbox，打上标签，再根据情况放到 Anytime 或 Someday。现在能做的留在 Anytime，暂时还没决定要不要做的放进 Someday，需要今天处理的再放到 Today。

买一本书、回复一条消息、记下一件以后想做的事，这种不需要太多上下文的任务，Things 3 管起来很舒服。[Things 的清单安排说明](https://culturedcode.com/things/support/articles/2803579/)。

## 但有些任务，几行备注放不下

比如一份学校作业，你可能需要保存老师给的要求、一张图表、几段参考资料，还想记下自己为什么这样写。

Things 3 有任务备注，也支持 Markdown 格式。但它不支持图片或附件。你可以放外部文件的链接，却不能把图片直接留在任务里。对我来说，有些内容只用文字描述，总是太过苍白。[Things 笔记与图片说明](https://culturedcode.com/things/support/articles/4438545/)。

我想写的不只是一句补充说明。老师为什么这样要求，我为什么这样理解，做的时候又遇到了什么问题，都应该有地方留下来。像写一篇完整的笔记一样，而不是到处放链接。

Void Calendar 想保留 Things 3 那种优雅、简单的感觉，同时给任务留出完整的笔记空间。每个任务都有关联的同名笔记，你可以记录当时的思路、做过的尝试，以及踩过的坑。

这些记录也能交给 AI 整理归档。下一次遇到同类任务时，AI 在规划中可以结合之前的经验，提醒你先注意哪些问题，避免再走一遍相同的弯路。记录下来的心得，能接着帮助后面的任务。

## 我还需要清单之外的安排

Things 3 可以在 Today 和 Upcoming 里显示 Apple 日历事件，但它的主要工作方式仍是任务清单，没有按时段排列任务的完整日历视图，也没有 Kanban 看板。[Things 日历连接说明](https://culturedcode.com/things/support/articles/2803583/)。

当课程、作业和生活里的事情挤在一起时，我需要的不只是选出今天要做什么，还需要知道一天里有没有时间做，以及任务之间应该怎样衔接。

Void Calendar 可以让 AI 把目标拆成小任务，结合已有日程安排时间。你也可以选择自己正在使用的 Claude Code、Codex 等 AI 客户端，或者连接自己的模型。

Things 3 提供快捷指令、URL Scheme 和 AppleScript 等自动化方式，也能通过苹果的 AI 功能或第三方工具扩展工作流；它没有应用内可安装的插件系统，也没有直接连接这些 AI 客户端的官方集成。[Things 第三方 AI 工具说明](https://culturedcode.com/things/support/articles/5510170/)、[Things 自动化方式](https://culturedcode.com/things/support/articles/2967034/)。

Void Calendar 的插件系统则可以把任务接着交给 AI：先拆分、再安排时间，适合由 AI 执行的部分，还能直接交给它完成。任务的笔记和结果也留在工作空间里，方便继续推进。

我依然喜欢 Things 3，也会继续用它记录轻量任务。但我仍然需要一个更强大的工具，帮我管理混乱的生活，把笔记、任务和时间真正放在一起。

Void Calendar，就是我给出的答案。

## 怎么选

选 Things 3，如果：

- 你需要 iPhone、iPad 或 Apple Watch 上的原生应用，现在就要。
- 你的任务大多是轻量的待办，不需要长笔记或图片。
- 你喜欢一次买断、不订阅，看清单就够了。

选 Void Calendar，如果：

- 你主要在 Apple 芯片的 Mac 上工作。
- 你想看到时间盒和日程排在一起，而不只是一份今天的清单。
- 你希望每个任务都有完整的笔记，并让 AI 用你自己的模型安排时间。
