Org mode 非常强大，我过去也常常使用它。任务、大纲、笔记和时间记录都可以放在 Org 文件里，再通过自己的配置，把它们组织成一套顺手的工作系统。

但用久了以后，我发现自己也花了不少时间维护这套系统。尤其是想在电脑和手机之间接着做事的时候，文件同步、手机上的操作，以及图片和附件，都需要额外考虑。

## 有优秀的 Web 端，还是要把同步接起来

Org mode 有 [organice](https://github.com/200ok-ch/organice) 这样优秀的 Web 端，可以在手机和桌面浏览器里使用 Org 文件。

只是对我来说，能在浏览器里打开文件，还没有解决全部问题。文件放在哪里，怎样同步，换到另一台设备后能不能接着编辑，仍然需要自己安排。手机上临时记一件事、查看任务，再回到电脑继续做，也没有达到我想要的方便程度。

Void Calendar 为 Android 和 iOS 开发了专门的客户端，同时支持 macOS、Linux 和 Windows。你可以在不同设备上使用日历、任务和笔记，也能得到适合各个平台的原生交互体验。

比如在学校用手机记下老师布置的作业，回到电脑再拆步骤、安排时间。我希望这些操作就是打开应用后接着做，而不是每次先想这份文件该怎样在设备之间流转。

## 贴一张图片，也不想先处理配置

做笔记的时候，你可能只是想把一张截图贴进去：老师讲过的图表、作业要求，或者自己查到的一段资料。

Org mode 支持图片链接和附件。但要把图片粘贴、保存位置和跨设备访问组织成自己习惯的方式，我当时还是需要写配置、选择工具，再把这些操作接起来。[Org mode 附件说明](https://orgmode.org/manual/Attachments.html)。

我当时确实写过一套复杂的配置。弄好的时候很有成就感，但换设备、改习惯，又要回来调整。后来我更想把时间用在事情本身：想到就记，打开就能做。

## 后来我还是选择了 OmniFocus

最后，我离开了那套花了很多时间配置的 Org mode 工作流，选择使用 OmniFocus。

Org mode 的强大并没有改变，只是我当时更需要一个打开就能开始管理任务的应用。对我来说，少一点配置和维护，能让我把注意力留给真正要做的事。

这也是我做 Void Calendar 时在意的地方：手机上随手记录，电脑上继续推进，任务、笔记和日历放在一起，用适合设备的方式操作。
