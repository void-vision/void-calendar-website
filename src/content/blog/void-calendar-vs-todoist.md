我对清单工具有一个很朴素的要求：想到的时候好记，打开的时候好找。

**一句话结论**：需要在手机、电脑和网页之间随时记任务，靠项目、标签和筛选管理一大堆待办，Todoist 很成熟，值得继续用。如果你在 Mac 上工作，希望每个任务都带着笔记和资料，让 AI 用你自己的模型把它们排进真正空闲的时间，数据也留在本机，可以试试 Void Calendar。

## 一览对比

| | Void Calendar | Todoist |
| --- | --- | --- |
| 平台 | macOS（Apple 芯片），公开测试版 | Web、Mac、Windows、Linux、iOS、Android |
| 价格 | 免费版含全部功能；Pro 同步暂未开放 | 有免费版；Pro 年付每月 5 美元 |
| AI 排程 | 用自己的模型，排进空闲时间 | Todoist Assist、Ramble 语音录入 |
| 日历连接 | Apple、Google、iCloud 日历 | 可同步到 Google、Outlook 日历 |
| 任务与笔记 | 每个任务配笔记，支持 [[ ]] 链接 | 项目、标签、筛选和任务时长 |
| 数据存放 | 存在你的 Mac 本地 | 云端账号，多设备同步 |

*竞品信息核对于 2026 年 10 月 8 日，以官网为准；Void Calendar 为公开测试版。*

Todoist 的项目、标签和筛选，很适合把一大堆待办整理清楚。麻烦是，清单整理好了，今天还是可能做不完。把十件事都放进“今天”，一天也不会多出几小时。

## Todoist 已经在把清单往日历里放

Todoist 有任务时长和日历布局，也能连接 Google、Outlook 日历，把安排好的任务同步过去。日历布局和时长功能有套餐要求。[任务时长说明](https://www.todoist.com/help/todoist/features/set-a-task-duration-L1kYkZv8d)、[日历连接说明](https://www.todoist.com/help/todoist/integrations/use-the-calendar-integration-rCqwLCt3G)。

所以区别不能停留在“Todoist 列任务，Void Calendar 排时间”。两边都能给工作留时间，接下来要看任务的内容怎样跟过去。

## 我不想在开始的时候重新做一次准备

比如“完成课程报告”。清单里写下这个标题很快，但真正开始时，还要找作业要求、上周的课堂笔记，以及老师给过的反馈。

Void Calendar 把任务和同名笔记连起来。你可以写清楚这次只查三份资料，还是要完成第一版提纲；做的时候也能把心得、踩过的坑留下来。

再让 AI 根据这些内容拆任务、安排时间。需要先查资料、再写正文的工作，也能通过依赖关系接着往下走。AI 不是只能处理一串没有上下文的标题。

## 顺手的清单，可以继续用

目前 Void Calendar 还不能直接连接 Todoist，这项集成在计划中。在那之前，顺手的收集清单可以继续放在 Todoist；决定要认真推进的工作，再放进 Void Calendar，和项目笔记、其他日程一起安排。

## 怎么选

选 Todoist，如果：

- 你今天就需要在手机、Windows 或网页上管理任务；
- 你的任务很多，主要靠项目、标签和筛选来整理；
- 你已经习惯把安排好的任务同步到 Google 或 Outlook 日历。

选 Void Calendar，如果：

- 你主要在 Apple 芯片的 Mac 上工作；
- 任务开始前需要资料、步骤，做完还想留下记录；
- 你想用自己的模型和 API Key 让 AI 拆任务、排时间；
- 你更希望任务和笔记存在自己的电脑上。

我的想法很简单：捕捉要轻，执行要清楚。轻量的小事，一行标题就够了；需要认真推进的工作，应该有地方放资料、步骤和记录。
